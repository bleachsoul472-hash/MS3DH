# مشروع MS3DH NEXUS — الربط التلقائي

المشروع يحتفظ بتصميم الموقع الأصلي، ويضيف وظيفة Netlify آمنة تجلب حالة Kick وإحصاءات Discord من الخادم. **لا تضع توكن البوت في HTML أو أي ملف يُنشر للعامة.**

## نشر المشروع
1. فك ضغط ملف ZIP على جهازك.
2. ارفع مجلد `MS3DH_NEXUS_Auto_Project` إلى مستودع GitHub، ثم اربطه بموقع Netlify، أو ارفع المجلد عبر طريقة النشر التي تدعم Netlify Functions. لا ترفع `index.html` وحده؛ يجب أن يُنشر مجلد `netlify/functions` أيضًا.
3. من Netlify افتح: **Site configuration → Environment variables** وأضف المتغيرات التالية. بعد ذلك أعد نشر الموقع.

## متغيرات Netlify المطلوبة

| المتغير | القيمة |
|---|---|
| `KICK_CHANNEL_SLUG` | `i5vb` |
| `DISCORD_BOT_TOKEN` | توكن بوت Discord — سرّي ولا تشاركه |
| `DISCORD_GUILD_ID` | معرّف سيرفر Discord |
| `DISCORD_ADMIN_ROLE_IDS` | معرّف أو معرّفات رتب الإداريين، مفصولة بفواصل |
| `DISCORD_MOD_ROLE_IDS` | معرّف أو معرّفات رتب المودريترز، مفصولة بفواصل |

يمكن ترك متغيرات الرتب فارغة مؤقتًا؛ ستظهر أعداد الرتب `—` بدل اختلاق أرقام. أعداد الرتب تحسب أعضاء فريدين يحملون واحدة على الأقل من الرتب المحددة.

## إعداد بوت Discord
1. افتح [Discord Developer Portal](https://discord.com/developers/applications) وأنشئ Application ثم Bot.
2. فعّل **Server Members Intent** من صفحة Bot (قد يكون الوصول إليه مقيدًا حسب حجم السيرفر وسياسات Discord).
3. أضف البوت إلى سيرفرك بصلاحية `View Channels` على الأقل، واسمح له بالوصول إلى السيرفر وقراءة قائمة الأعضاء. لا تمنحه Administrator إذا لم تكن بحاجة لذلك.
4. انسخ Bot Token مباشرة إلى متغير Netlify `DISCORD_BOT_TOKEN`، ولا ترسله في المحادثات ولا تضعه في ملفات الموقع.
5. فعّل Developer Mode في Discord، وانسخ Server ID إلى `DISCORD_GUILD_ID`، وانسخ IDs رتب الإداريين والمودريترز إلى المتغيرين المناسبين. افصل أكثر من رتبة بفاصلة.
6. أعد نشر Netlify. اختبر `/.netlify/functions/status` في موقعك؛ يجب أن يعرض JSON بحالة Kick وDiscord.

## ملاحظات مهمة
- حالة Kick تعتمد على نقطة بيانات عامة غير موثقة رسميًا وقد تتغير أو تتوقف؛ عند تعذر التحقق سيظهر «حالة البث غير متاحة مؤقتًا» بدل عرض حالة غير مؤكدة.
- Discord يعيد أعداد الأعضاء والمتصلين التقريبية من `with_counts=true`. أعداد الرتب تحتاج صلاحية قراءة قائمة الأعضاء وميزة Members Intent. في السيرفرات الكبيرة جدًا، فحص القائمة قد يستغرق وقتًا أو يتطلب تصميمًا مجدولًا لتخزين النتائج مؤقتًا.
- الوظيفة تُحدّث عند فتح الموقع وكل 60 ثانية من جهة المتصفح. يمكن إضافة caching/جدولة لاحقًا إذا كان السيرفر كبيرًا.
- لوحة الموقع الموجودة مسبقًا تحفظ كثيرًا من التعديلات في المتصفح المحلي فقط؛ هذا الربط التلقائي لا يحول لوحة المحتوى إلى نظام CMS مشترك بين الأجهزة.
